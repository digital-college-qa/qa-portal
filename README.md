# QA Portal

Учебный портал Digital college для практики тестирования на русском и казахском языках.

Сайт: https://digital-college-qa.github.io/qa-portal/

Репозиторий: https://github.com/digital-college-qa/qa-portal

`index.html` открывает портал, `home.html` — учебный магазин кофейни. Уроки находятся в `learn.html`, база знаний — в `kb.html`, требования — в `docs.html`, тестовые данные — в `testdata.html`, выбор версии стенда — в `releases.html`.

Кофейня называется **qala coffe**, портал — **QA Portal**. `labs.html` показывает магазин и плавающие окна инструментов. Учебный API уже меняет цены и корзину в браузере. Настоящий Playwright запускается сервером из `server/`; для общего доступа подготовлены Docker и вход по логину/паролю. Архитектура описана в `docs/training-platform.md`, развёртывание — в `server/README.md`. Материалы ментора находятся вне этого публичного репозитория.

Это статический сайт на HTML, CSS и JavaScript без сборки. GitHub Pages публикует корень ветки `main`. Для локального запуска из этой папки:

В шапке всех страниц есть кнопка «Тема»: светлая, тёмная, тёплый песок, шалфей, сумерки, режим устройства и своя палитра. Настройки хранятся локально в `qc_appearance`; фон, панели, текст и акцент можно менять цветовым полем или HEX-кодом. Нечитаемые сочетания текста и фона автоматически корректируются. `js/theme.js` подключается в `<head>`, чтобы применить сохранённый выбор до отображения страницы. В теме Agile базы знаний доступны оригинальные векторные схемы на русском и казахском; лицензия и источники — в `img/methods/README.md`.

```sh
python -m http.server 8765
```

После запуска откройте http://localhost:8765/.

В магазине намеренно заложены учебные ошибки. Версии **1.0 / 1.5 / 2.0** имеют отдельные каталоги, состояния и требования. 2.0 опубликована как предварительная версия: весь запланированный набор сложных сценариев ещё не завершён. Не исправляйте учебные ошибки попутно с изменениями портала и не раскрывайте их студентам в уроках или базе знаний.

Язык и выбранная версия хранятся в `qc_lang` и `qc_version`. Данные стендов разделены: например, `qc_v1.5_cart`, `qc_v2.0_cart`. Прежние данные старого 1.0/1.1 остаются в браузере, но не импортируются в новые стенды. Все аккаунты кофейни — учебные, с вымышленными данными.

Запуск Playwright с ноутбука через кнопки существующего Discord-бота описан в `server/LAPTOP.md`. Docker оставлен как отдельный вариант будущего Linux VPS.

При изменении JavaScript портала обновляйте параметры версии ресурсов в HTML, чтобы браузеры получили новые файлы.
