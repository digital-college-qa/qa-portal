# Управление уроком из Discord

Бот уже работает в Cloudflare. На ноутбуке нужен агент `discord-agent.mjs`: он обращается к боту исходящими HTTPS-запросами и получает только намерения «запустить»/«остановить». Открывать порт роутера, SSH или покупать VPS не нужно. Агент не принимает удалённый код или команды оболочки.

## Для ментора

1. После включения ноутбука открыть **Запустить агент Discord.cmd** из этой папки. Оставить его окно открытым. В текущей установке агент также можно запустить скрыто; выключение ноутбука его завершит.
2. В Discord открыть **🛠-журнал** → **▶ Запустить сервер QA**.
3. Через 15–60 секунд нажать **🖥 Статус сервера**. Бот покажет личным ответом ссылку лаборатории, логин класса и новый пароль урока. Передать их ученикам. Пароль не публикуется в общем канале.
4. Ученики открывают ссылку, вводят логин/пароль в окне автотестов и запускают тесты прямо на QA Portal. Адрес сервера подставляется из ссылки; пароль в URL не попадает.
5. После занятия нажать **■ Остановить сервер QA**. Закрываются runner, браузеры и Cloudflare Tunnel. Агент остаётся на связи и может снова запустить занятие.

Управлять кнопками может только аккаунт `DISCORD_MENTOR_USER_ID` на заданном Discord-сервере. Роль помощника не даёт этого права. Если ноутбук выключен или агент не запущен, бот сообщит об этом и не поставит отложенный запуск. Сам ноутбук кнопка не включает.

Автоостановка — через 4 часа. При потере связи с ботом дольше 90 секунд локальный сервер закрывается. При каждом новом старте создаётся другой пароль. Доступ ограничен двумя одновременными запусками Playwright, пятью запусками в минуту на сессию и 45 секундами на запуск; при занятых двух слотах ученикам нужно подождать. Для параллельной работы класса можно выдать отдельные аккаунты через `manage-users.mjs` и серверный Docker-режим.

## Перенос на другой ноутбук

- Node.js 22+, `npm ci` в папке `server`, Chromium: `npm exec -- playwright install chromium --only-shell`.
- Скачать официальный `cloudflared` для Windows x64 в `server/tools/cloudflared.exe`. Текущая проверенная версия: **2026.10.2**, SHA-256 `12c7c887f8aaab779aef1dfa9b60673530a5adb88ecc55dd6df8f56e0b70f199`.
- Локальный `server/secrets/discord-agent.json` содержит адрес бота и отдельный ключ агента. Он исключён из Git; не отправлять его студентам или в общий чат. Токен Discord-бота агенту не нужен.
- Запустить агент и проверить кнопки начала, статуса и остановки. Windows-режим работает без Docker; Docker Compose сохранён для будущего Linux VPS.

Временные адреса Cloudflare меняются при новом старте и не имеют гарантии доступности. Это подходит для учебного пробного запуска. При стабильном расписании можно позже подключить именованный туннель. Официальная справка: [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
