# Agile, Scrum and Kanban illustrations

Six original SVG diagrams created for QA Portal on 2026-10-23: three topics in Russian (`ru`) and Kazakh (`kz`). No external images, logos, fonts or raster assets are embedded. All SVG artwork in this directory is dedicated to the public domain under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ .

These are original explanatory examples, not reproductions of diagrams from the references. The coffee-shop tasks and WIP limits are illustrative.

Methodology references:

- Agile principles: https://agilemanifesto.org/iso/ru/principles.html
- Scrum Guide 2020: https://scrumguides.org/scrum-guide.html
- The Kanban Guide, May 2025: https://kanbanguides.org/the-kanban-guide/

Scrum events are shown inside the Sprint. Testing happens throughout the Sprint. The two-week duration is an example; a Sprint is one month or less. The Kanban example shows a pull system and WIP controls; Kanban can be used alongside Scrum.
