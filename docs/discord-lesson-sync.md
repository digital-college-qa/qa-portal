# Синхронизация уроков с Discord

Сайт публикует `data/lesson-catalog.json`: номера и названия всех 26 пар единого курса (`courses.qa`), язык, краткую практику и признак устного занятия. Каталог собирается из тех же файлов, которые загружает `learn.html`.

После изменения уроков выполните `node scripts/build-lesson-catalog.cjs`. Тест `lesson-catalog.test.cjs` не пропускает устаревший каталог.

Discord-бот читает опубликованный каталог при открытии выбора пары и повторно перед отправкой. Номер, название карточки и ссылка на урок берутся из одной версии. Если нумерация изменилась, старое открытое меню обновляется и просит выбрать пару заново. При недоступности сайта сохраняется последняя полноценная копия.

Резервная копия в коде бота обновляется командой `node build_tasks.mjs`. Для сборки из готового опубликованного каталога можно указать `--catalog <путь к JSON>`. После изменения только уроков развёртывать бота заново не требуется.

Устные пары не требуют письменной сдачи в карточке Discord. Проверка состояния развёрнутого бота: `GET /curriculum` — только публичные названия уроков и версия каталога, без учётных данных.
