# Словари и сокращения уроков

REG и BTN показываются только при появлении в тексте. Коды разделов — локальная договорённость проекта.
Словарь слева следует языку портала и всегда сохраняет английский перевод.
На узком экране два справочника превращаются в раскрываемые блоки над уроком.

Для двухуровневых уроков основной список берётся из `terms` самого урока.
Для проектных пар 18–26 основной словарь задан в `projectTerms` файла `js/learn/lesson-reference.js`;
при смене темы этих пар обновить и его. Совпавшие термины связанных тем базы знаний и статусы дополняют список.
Сканирование включает оба уровня, заполненный образец и задание, но не ссылки и заметки преподавателю.
Коды внутри новых SVG вычисляет `scripts/build-lesson-illustrations.py` и сохраняет в `referenceCodes`.
